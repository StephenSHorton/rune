- **Kit: `Slider`.** A horizontal slider: `Slider::new(value).range(min, max).step(s).width(w).label("Volume").on_change(|s: &mut App, v, tx| ..)`. Dragging the knob moves the value (grabbing it off-centre doesn't jump it), pressing the track jumps there, and while focused the arrow keys, Page Up/Down, Home and End step it. Values are clamped to the range and snapped to the step; a cancelled drag reports the value it started from. `.on_commit` hears only settled values (a released drag, a key step), for saving once. It reads as a slider with its value (`.value_text` formats it), and `.disabled(true)` fades it and drops its input.
