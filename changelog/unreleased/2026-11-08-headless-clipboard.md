- **Headless runs have a clipboard.** A `--snap` or `--script` run (and each window of a `--desktop` run) copies to an in-memory clipboard, `HeadlessRun::clipboard()`, instead of dropping the copy, so a `Tx::copy_checked` callback hears `Ok(())` and an app can show and test its "Copied" state; `MemoryClipboard::text` reads what was copied and `fail_writes` makes later copies answer `Err`. A paste in the run reads it too. The OS clipboard is still never touched.
