- **File dialogs pick several files.** `Tx::open_files` and `FileDialogs::open_files` answer with every chosen file in order (empty when cancelled), through rfd's `pick_files` on macOS and Windows and the portal's `multiple` choice on Linux. Headless runs show it as `"kind": "files"` and a script answers it with `{"type": "file-dialog", "paths": [..]}` (`ScriptEvent::FileDialogFiles`); tests use `Runtime::resolve_file_dialog_files` and `FileDialogs::scripted(..).then_files(..)`. `FileDialogKind` gains `Files`, so an exhaustive match needs the new arm.
